# Domain

本仓库只维护 Ops Vibe Coding 的方法论、工作流、教程、引用和示例。

- `personal-skill` 是可执行 Skill 的来源，本仓库不复制其实现。
- Prototype、Architecture、Spec、Ticket、Review 和 Test Report 是不同阶段的契约，不能互相替代。
- 项目坚持 Operations-first、Evidence before complexity、One ticket one context 和 Human acceptance。
- 文档修改应保持简短、流程优先、示例驱动，并明确 Why、Input、Action、Output、Gate、Next。
